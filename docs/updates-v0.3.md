# v0.3.1 · 双环与双光轨

新增日常池总余额统计；双环左右均衡排布。灵活池水位按余额连续变化，收款扩散波纹与入水、支出收拢波纹与抽水反馈，小额变动也有方向提示。外环／第一条为今日额度（或用户选择的总可消费预算），内环／第二条始终是日常池总余额。所有数值直接来自账本；比例以累计有效入池为参照，结算重算不会重复计入，历史归档不重复扣款。统计不改变账目和规则。

保留原有圆环／线形外观切换，兼容黑白主题和减少动态效果。50 项隔离测试覆盖结算、撤销、资金池转入和负余额。

# v0.3.0 · 蓄水池、保险柜与共享账本

- 灵活池蓄水、水位升降；固定池保险柜解锁、开门与存取动画。以服务器确认后的余额为准，支持减少动态效果。
- 三个资金池均可直接修改金额，保留原因与调整流水；池间调拨与真实收支分开记账。
- 修复窄屏按钮挤压、金额断行、表单错位，以及并发刷新时的旧响应覆盖。
- 离线迁入历史支出，保存原始字段与预算快照，重复导入不重复记账，也不再次扣减当前余额。
- 原始归档仅账本本人可下载；Agent 凭据无权读取原始迁移档案。
- Harness 旧工具适配器连接同一账户账本；复用标准 MCP 传输的 HTTPS、证书校验和幂等保护。
- 多私有接口监听示例，复用一个账本实例和一个调度器。默认仅监听回环地址。

升级前备份数据目录。原有账户和 SQLite 数据兼容，无需重新导入。旧账导入只用于切换日之前的历史记录，必须先核对并初始化切换日余额。

验收使用隔离的虚构账本。新增迁移、撤销、精度、回滚、归档隔离和适配器测试；不向真实账本写入测试交易。
