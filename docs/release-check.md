# v0.2.0 发布验收

检查日期：2026-10-27。所有功能测试使用临时数据库或明确标记的虚构演示数据。

## 功能

- 40 项自动测试：整数金额、日常 / 灵活拆分、余额不足、结余划转、补记、撤销、规则版本、重复请求与并发请求、短月计划、离线补跑、对账差异、赤字事件恢复与去重。
- HTTP / MCP 端到端：真实本机后端、MCP 初始化、工具发现、查询、幂等记账。
- 安全边界：未登录隔离、只读 / 读写 / 预算管理权限、不能升级令牌、撤销即时生效、Cookie / CSRF、Origin / Host、防 CSV 公式注入；新增网页与 Agent 同账号、跨用户隔离、密码哈希、重置与停用后失效、登录限流。
- WebUI：桌面与 390px 手机断点；黑白主题、圆环和线形额度条、默认资金池、自动补足、赤字整页状态、指南入口。无横向页面溢出；控制台检查无前端错误。新版粒子动画在此次浏览器测得 1,602 ms / 96 帧（约 60 FPS），不是对所有设备的性能保证。浏览器实际导出 CSV：9 行虚构流水、13 列，中文列名及金额单位正确。
- Python wheel 构建成功，含 WebUI 与独立指南，不含运行数据库或令牌。

## 公开内容

独立初始化 Git 仓库，不继承运维仓库或用户账本历史。仅提交原创源码、测试、文档、虚构演示截图与占位接入配置。

发布前执行：

1. 对全部暂存文件做私人标识检查。私有标识清单保存在仓库外，不发布。
2. 用官方 Gitleaks 8.30.1 扫描暂存导出内容，默认规则，无禁用密钥检测规则；日志启用脱敏。
3. 初始提交后扫描全部可达 Git 历史，再执行私人标识检查。
4. 核对发布包不包含数据库、口令、配对凭据、真实账目或私有主机配置。
5. Git 作者使用公开的 GitHub noreply 邮箱。

上述扫描未发现匹配泄露项。这是发布前的自动检测与人工审查，不代表第三方渗透测试或绝对安全保证。
